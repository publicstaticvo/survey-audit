# SurveyAudit Skills

Read the requested Skill and follow its links from this package. Retain stable evidence IDs when composing investigations. Read the Audit Contract when auditing a paper and document unresolved findings with the missing evidence and its impact. Use the legacy mapping before interpreting SurveyAudit records. Validate report JSON and regenerate Markdown after edits. Use local artifacts or authorized source material.

For framework changes, follow [CONTRIBUTING.md](CONTRIBUTING.md). Keep the category definitions, obligations and investigation procedures independently editable.
